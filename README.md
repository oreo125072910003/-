# 小助手 DSH

当前发布版本：**0.3.12**，2026-10-26。

## 我只想打开小助手

这台电脑：打开 `G:\小助手`，双击 **`启动最新版.cmd`**。

下载压缩包：解压整个 `小助手-0.3.12-完整版.zip`，双击包内 **`启动小助手.cmd`**。保留旁边的“程序文件”文件夹，EXE 所需组件都在里面。

源码工程：双击根目录的 `启动小助手.cmd`，自动选择当前版本；开发者先运行 `npm ci` 和 `npm run package`。

## 这一版包含什么

- 小助手桌面程序、合同工具、DSH 产品连接插件和完整源码。
- 能力中心的一键选择与保存、电脑与文件开关、微信 Word/Excel 附件读取。
- 微信回复归属修复：桌面负责回复时，旧回复进程不会再次启动抢答。
- 一个明确的启动入口，历史说明归档到文档目录。

小助手的核心始终是 DSH，默认复用已登录的 Harness 账户；微信继续使用已配置的匹配微信客户端和读取服务。压缩包不包含个人账户、密钥、聊天或邮件数据，已有安装继续使用原数据。换电脑时需要配置该电脑上的 DSH 与微信环境。

## 首次使用和升级

1. 双击启动入口，打开“能力中心”，查看 DSH 是否已连接。
2. 更新连接插件后，如果界面显示“等待重载”，从系统托盘完整退出并重新打开 DSH。
3. 在微信页核对账号及允许回复的会话。只处理连接后到达的新消息。
4. 使用新版本前先从旧小助手的系统托盘退出；关闭窗口通常只是收起到托盘。

电脑能力目前覆盖截图、命令和文件操作；通用鼠标键盘控制尚未接通。新版真实电脑操作及微信附件投递的验证状态见发布说明，不能把开关已启用视为功能已经全部验收。
