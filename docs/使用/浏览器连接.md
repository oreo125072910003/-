# 让小助手使用已登录的 ChatGPT 网页

小助手 0.3.15 会检查浏览器扩展安装位置，优先连接已安装扩展的 Edge。首次使用需要安装扩展并允许连接页面。已配置 `PLAYWRIGHT_MCP_BROWSER` 时保留明确选择；程序不修改系统环境变量。

1. 用已经登录 ChatGPT 的 Edge 打开 [微软 Playwright Extension 安装页](https://chromewebstore.google.com/detail/playwright-extension/mmlmfjhmonkocbjadbfplnigmagldckm)。发布者为 Microsoft；这是 Chrome 应用商店的官方扩展，也供 Edge 使用。
2. 点击添加扩展，浏览器若显示安装确认，请本人核对并确认。
3. 保留已登录的 ChatGPT 网页。回到这里回复“装好了”，继续连接检查。
4. 第一次连接时，浏览器会出现选页界面。请选择愿意交给小助手的 ChatGPT 标签页并确认。登录验证仍由本人完成。

连接页的标签标题为 **Welcome**。在 ChatGPT 对应行点击 **Allow & select**；上方的风险说明是扩展权限提示，不是连接错误。`PLAYWRIGHT_MCP_EXTENSION_TOKEN` 用于可选的自动连接，不是普通连接的前提。首次连接预留五分钟，过期后应使用重新发起连接时打开的新页面。

连接后可以让小助手在网页中聊天和生成图片；无需另外填写 API Key。只有实际生成并下载的图片才会登记为小助手成果。遇到网页限额、登录要求或生成失败时，小助手应报告真实情况。

扩展安装、网页连接和真实出图分别验证。工具目录读取成功不能证明网页已经连接，网页连接成功也不能证明图片已经生成。
