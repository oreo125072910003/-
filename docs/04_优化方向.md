# 04 · 优化方向（按优先级）

## P0 · 稳定性（先别让主人再遇到"又连不上/又白屏"）

1. **账号守卫自动化**
   - 现状：登录错号要靠日志 `HOOK_ACCOUNT_MISMATCH` 事后发现；`_wait_login_and_restart.py` 已在等正确账号。
   - 目标：登录前主动检测当前微信账号；错号时在桌面弹窗/微信通知主人「请用物美价廉号登录」，并自动退出登录 → 出二维码。
   - 价值：避免"连不上"这类最影响体验的事故（今天发生 2 次）。

2. **挂载版客户端防替换**
   - 现状：用户从开始菜单/升级提示/官网重装都会启动官方 4.1.15.13，直接失去 hook。
   - 目标：把挂载版 exe 设为系统默认启动路径；重命名官方快捷方式；加计划任务开机校验（当前 Weixin.exe 路径与 hash 不符则告警并拉起挂载版）。
   - 价值：常驻防线。

3. **统一服务监督器**
   - 现状：pcbridge、reader、适配器、桥接、DSH 各自有/没有看门狗；DSH 重启会带走 pcbridge。
   - 目标：一个守护进程统一持有子进程（不挂在 DSH 进程树下），健康检查 + 指数退避重启 + 状态页。
   - 价值：一次 DSH 重启不再连带掉链子。

4. **白屏自愈**
   - 现状：只能手动跑 `restart_wx_software.ps1`（要手机确认）。
   - 目标：检测到白屏时先温柔重试（已做），仍白则在**无人聊天时段**自动重启客户端，并通知主人手机确认；或改用窗口截图回退为读库+坐标点击。
   - 价值：发文件/切会话不再靠人盯。

5. **配置即代码 + 自动备份**
   - 目标：`wechatagent.json`/人格/桥接配置纳入每日备份（`备份配置.bat` 已有，建议加计划任务 + 保留 30 天）；修改前自动打快照。
   - 价值：改坏了能回滚。

## P1 · 功能补全

6. **发文件到群全链路验收**
   - 等微信窗口正常后做真实测试：群消息落库校验 + 多发几个群 + 失败分类（白屏/指纹/前台被抢）。
   - 增加「发送演练」命令，一键验证某个聊天能不能发。

7. **合并转发文件落地**
   - 现状：只给出本地缓存路径。
   - 目标：按 CDN 信息（authkey 有有效期）下载到工作区，失败给明确提示；对文本类合并记录生成结构化摘要。

8. **链接/卡片增强**
   - 公众号/B站/小红书：抓标题+正文（read_web_page 已能读 B 站），失败时统一给"请复制链接"的提示。
   - 视频号/小程序：至少给出『这是什么、原链接』。

9. **表情包图库扩容 + 自动采集**
   - 现状：24 张 + 收集分享。
   - 目标：收集群里表情入图库、去重、按情绪打标签；斗图命中率提升。

10. **记忆与画像**
    - 成员记忆已有雏形；补：长期偏好、称呼、禁区；跨会话共享。

11. **多模态**
    - 收图片已可用；补：对图片做理解（截图问答/文档 OCR/合同识别接入）。

## P2 · 工程质量

12. **两份项目文件单一来源**
    - 现状：`data\workspace` 与 `app\resources\project` 手工同步，容易漏。
    - 目标：写 `sync-project.ps1`（白名单复制 + 自动更新 deployment.json 哈希 + 校验），或直接把 app 副本改为 Junction/发布时生成。
    - 价值：少一类"升级后改动丢失"的坑。

13. **自动化测试**
    - 现有：零散 `_test_*.mjs` / `_test_*.py`。
    - 目标：补关键回归（消息解析、标题指纹、10 分钟规则、任务播报、工具授权）；改代码前跑一遍。

14. **日志与观测**
    - 日志轮转/归档；控制台加「概览」：今日消息数、失败发送数、白屏次数、任务数、错误 top。
    - 告警：hook 断、账号错、pcbridge 挂 → 直接给小助手发一条内部通知。

15. **安装/交接包**
    - 目标：一个安装脚本搞定目录、快捷方式、计划任务、token 配置（不含密钥）、体检。
    - 现在已有 `G:\小助手` 入口 + 文档 + 打包（本包）。
