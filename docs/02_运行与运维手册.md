# 02 · 运行与运维手册

## 一、日常启动 / 停止

三种方式任选：

1. **双击脚本**（推荐）：`G:\小助手\启动小助手.bat` / `停止小助手.bat` / `重启并应用.bat` / `查看状态.bat`
2. **控制台**：打开 WeChatAgent → 右上角「重启并应用」/「停止」
3. **命令行**（管理员 PowerShell）：
   ```powershell
   powershell -ExecutionPolicy Bypass -File "G:\wechat-deepseek\data\workspace\scripts\manage.ps1" -Action start   # 或 stop / restart / status
   ```

启动顺序：`project-config` → reader(5031) → weflow 同步 → hook-onebot(11229) → DSH 插件(11230) → 社交桥。
停止顺序相反。

## 四、常见故障速查

### 1) 小助手完全不回话

症状：微信里发消息没反应，日志无 `[Social]` 行。

排查顺序：
1. 微信是不是**官方版 4.1.15.13**？官方版没有 hook → 必须用挂载版 4.1.10.27。
2. `30001` 是否在监听：`Test-NetConnection 127.0.0.1 -Port 30001`
3. hook 是否 ready / 账号对不对（见第二节）
4. 控制台是否 `ready:false`、`services.bridge=false`

处理：
```powershell
# 用挂载版客户端重启（软件渲染，治白屏；会要求手机确认登录）
powershell -ExecutionPolicy Bypass -File "F:\deepseek工作区\wechat-pc-bridge\restart_wx_software.ps1"
```

### 2) `HOOK_LOGIN_REQUIRED` / 一直提示手机确认

挂载版客户端登录态失效。手机微信弹出「登录确认」时点确认；
超过约 15 分钟确认窗口失效，需要重新在客户端点「登录」再确认。

### 3) `HOOK_ACCOUNT_MISMATCH`（最坑）

原因：**挂载版微信登录成了别的号**（比如主人自己的号），不是「奥利奥物美价廉」。
校验逻辑：`scripts\wechat-account-check.mjs` 拿 `health.databaseAccounts[0]` 与 reader 的数据库目录名（`wxid_579nqogdaa5n29_b8df`）比对。

处理：在微信客户端「切换账号/退出登录」，用**物美价廉的手机**扫码/确认登录。
登录成功后运行一次「重启并应用」。日志里能看到 `HOOK_ACCOUNT_MISMATCH_WAITING` 说明后台等待脚本正在等正确账号（`_wait_login_and_restart.py`，`EXPECT_ACCOUNT` 默认物美价廉）。

### 4) DSH 里 `mcp__pcbridge__*` 工具全没了

原因：电脑桥接服务由 DSH 应用进程树启动，**DSH 应用重启会把它带走**；DSH 启动时连不上就把这组工具加载失败（工具目录里 0 个）。

处理：
```powershell
Start-Process wscript.exe '"F:\deepseek工作区\wechat-pc-bridge\start_hidden.vbs"'
# 再重启一次 DSH 桌面应用（工具目录只在应用启动时抓取）
```
看门狗 `dsh-pcbridge-watchdog` 已配置（每 20 秒检查，隐藏窗口），正常情况下 8~12 秒内自动恢复服务；
但 DSH 应用内的工具目录仍需重启应用才能刷新。

### 5) 微信窗口白屏（发文件/截图失败）

症状：`bridge.log` 里 `[wx] 微信窗口白屏,无法校验标题`、`发送后没查到新文件记录`。
原因：Qt/GPU 在虚拟显示器（向日葵 OrayIddDriver / GameViewer）下渲染失效；UI 自动化/Switch 会话/截图全受影响。
微信**文本/图片发送走 hook，不受影响**；只有「发文件」和「UI 切会话」依赖窗口画面。

处理：
1. 先试无损：最小化再还原、Ctrl+F 切聊天、隐藏/显示；
2. 仍白屏 → 用 `restart_wx_software.ps1`（软件渲染重启，需手机确认一次登录）；
3. 避免脚本在游戏全屏/其他窗口抢前台时操作微信窗口。

### 6) 发文件到群失败（`发送后没查到新文件记录`）

发文件链路：`tool_export_file` → `send_wechat_native.ps1 -Mode file` → 微信 UI（选文件→发送）→ 读库校验文件消息。
常见原因：
- 微信窗口白屏/被遮挡 → 见上一条
- 标题指纹失效（`SCAN_NO_MATCH` / `TITLE_REF_DUPLICATE`）→ 重拍：
  ```powershell
  powershell -ExecutionPolicy Bypass -File "F:\deepseek工作区\wechat-pc-bridge\send_wechat_native.ps1" -CaptureTitle -TargetTitle "群名" -SwitchChat
  ```
  指纹文件在同目录 `_wx_title_<hash>.png`（hash = sha1(utf8(群名)) 前 10 位），目标标题最多 12 个字符
- 发送前会校验：`DRYRUN_OK` 才算可发；`SCAN_NO_MATCH` 说明窗口布局/标题不对

> 只有「主人私聊」允许失败后转图片兜底；群发失败会如实返回失败，不会乱发到别处。

### 7) 表情包显示成 `[表情]` 占位 / 图片 503

原因：表情 CDN `vweixinf.tc.qq.com` 解析出不可达 IPv6，连接超时。
已修：`scripts\wechat_sticker.py` 改为 IPv4 优先连接（`_ipv4_create_connection`）。若复发检查该文件两份副本是否同步。

### 8) 群消息过了 10 分钟还被回复

规则在 `components\qq-bridge\src\core\social-engine.js`：`staleGroupMs=600000`，
入口丢弃（`stale_group_message_ignored`）、开跑前丢弃（`stale_group_batch_ignored`）、投递前兜底（`stale_group_reply_skipped`）。
日志里搜 `stale_group` 可确认生效。改阈值改 `staleGroupMs` 并重启并应用。

### 9) 同步人格/同步名称失败：`BEHAVIOR_CHANGE_NOT_ALLOWED`

原因：改了聊天人格但还没点「重启并应用」，`state\bridge-config.json` 里还是旧人格，插件会拒绝变更。
处理：先点「重启并应用」，等服务重启完成，再点「同步名称」。控制台已加拦截提示。

### 10) 任务通知太吵 / 想关掉

`config.json → job_notify`：`natural`(默认，自然语言汇报) / `fail`(只报失败) / `off`(完全关闭)。
改完不用重启（每次读配置）。

### 11) 控制台 API 打不开

端口是随机的：`Get-NetTCPConnection` 找 `WeChatAgent.exe` 的监听端口。
所有 `/api/*`（除 `/api/info`）都要带 `x-console-token` 请求头（值来自 `/api/info` 的 `token`）。

### 12) 看门狗每分钟弹黑框

已修：任务改为只跑一个隐藏的常驻 PowerShell 循环（`pcbridge_watchdog.vbs` → `pcbridge_watchdog_loop.ps1`），
不会再每小时/每分钟新建窗口。

## 五、几种「重启」别搞混

| 操作 | 影响 | 什么时候用 |
|---|---|---|
| **重启并应用**（控制台按钮 / `manage.ps1 -Action restart`） | 重启 reader/适配器/桥接，重读配置与人格，约 8–12 秒 | 改了 config/人格/清单/后端代码后 |
| **重启 DSH 桌面应用** | 重新抓取 MCP 工具目录（pcbridge/合同工具） | 新增/删除 MCP 工具、插件消失后 |
| **重启 pcbridge**（`start_hidden.vbs`） | 电脑桥接 8765 | 8765 挂了但不想动 DSH |
| **重启微信客户端**（`restart_wx_software.ps1`） | 客户端+hook，需手机确认登录 | 白屏、登录态失效、账号错误 |

## 六、改代码后的同步流程（必须做）

1. 改 `G:\wechat-deepseek\data\workspace\...` 的真项目文件；
2. 同步到 `G:\wechat-deepseek\app\resources\project\...` 同名文件；
3. `node --check` / `py_compile` 语法检查；
4. 更新 `G:\wechat-deepseek\app\resources\project\deployment.json` 里对应 `sourceHashes`（键为项目相对路径，值是 SHA256 十六进制）；
5. 在控制台「重启并应用」验证。

不更新 deployment.json 的后果：升级/校验时被判不一致，可能覆盖你的改动。

## 七、备份与恢复

- **备份**：`G:\小助手\备份配置.bat` → `G:\小助手\备份\备份_日期_时间.zip`（含 config、roles、bridge-config、social-messages 摘要、pcbridge 脚本）。
- **恢复**：停服务 → 覆盖对应文件 → 重启并应用。
- **回滚补丁**：所有代码补丁都保留 `.bak_*` 备份（如 `mcp_dsh_server.py.bak_filegroup`、`social-engine.js.bak_stale`）。
- **DSH 会话**：`C:\Users\ADMIN\.dsh\sessions\` 可整个备份，恢复时停 DSH 再覆盖。
