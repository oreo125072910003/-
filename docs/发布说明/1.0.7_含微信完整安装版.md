# 小助手 1.0.7：含微信的完整安装版

本版补齐 1.0.6 独立 Windows 安装器缺少专用微信的问题。**安装程序现在直接包含微信客户端、匹配连接组件、Python 和完整读取环境**，不再要求先找一个旧微信工程来导入。

从 [v1.0.7 Release](https://github.com/oreo125072910003/-/releases/tag/v1.0.7) 下载 `xiaozhushou-Setup-1.0.7.exe`。需要在 DSH 内使用的用户可选同页 `xiaozhushou-harness-host-1.1.5.tgz`，两种入口选择一种运行。DSH 仍是小助手核心，需要安装并登录已有账户；本包不复制 DSH 账户或绕过它。

## 安装后连接微信

1. 安装并打开小助手，进入左侧“微信通信”。
2. 点击页面上方“安装包已包含微信”卡片里的“准备并连接微信”。
3. 点击“准备专用微信”，等待包内组件校验并复制到小助手数据目录。
4. 点击“打开微信”，由你扫码或手机确认登录，等待聊天同步。
5. 点击“识别已登录账号”，选择账号，再“验证并连接”。如果提示等待密钥，按向导在专用微信退出账号后再登录。
6. 在微信页自行选择允许回复的聊天，再开启自动回复。

如果另一版微信正在运行，按提示从其托盘正常退出后再打开专用微信；不会强行结束你的客户端。已经导入的连接继续沿用，首次向导不会覆盖。安装器不包含原电脑的微信账号、令牌、密钥或聊天，新电脑会生成自己的连接配置。

## 本次修正

- 默认 Windows 安装包内置专用微信 **4.1.10.27**，组件实际位于 `resources/companions`；准备后的可写环境位于小助手个人数据目录的 `wechat-environment`。
- 独立桌面和 DSH 共用同一套四步向导与账号核验逻辑，避免两套功能出现遗漏。
- 微信页明确显示包内组件与准备入口；旧连接与手动导入放在次级设置。缺少组件时会明确提示缺少。
- 安装器构建必须逐文件核对微信、Python 与读取组件，拒绝缺失、篡改或混入个人状态的包。
- 安装验收必须在安装后的程序里实际点击准备、运行内置 Python/reader，再验证卸载仍保留生成的微信环境和个人数据。
- 保留主窗口调用核验，固定组件目录与程序；验证等待期间新增连接或取消时，不继续覆盖连接。
