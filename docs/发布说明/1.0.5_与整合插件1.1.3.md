# 小助手 1.0.5 与 DSH 整合插件 1.1.3

DSH 整合包文件名为 `xiaozhushou-harness-host-1.1.3.tgz`，从 GitHub Release `v1.0.5` 的附件下载。该文件本身就是压缩安装包，可以交给 DSH 插件管理器安装。

## 本次变更

- 修复微信长会话在纯文字轮次后恢复工具权限时，全部工具被延迟加载而无法回复的问题。
- 尊重已有 billion-context 的压缩所有者标记，避免产品原生上下文整理与其冲突导致请求失败。
- 纳入 Windows 客户端观察、点击、中文输入及截图回传能力。
- 纳入每分钟检查的新邮件微信通知，首次同步不补发历史邮件。
- 纳入长图局部阅读、多图预算分配与损坏局部容错。
- 纳入记忆、技能和插件的自我完善提案；实际变更须由主人在绑定微信私聊逐项批准。

DSH 始终是核心，沿用现有登录、模型和 high 推理等级。

## 安装

1. 在 Windows x64 电脑安装并登录兼容的 DSH；本轮实际宿主为 0.2.1-rc.3。
2. 若本机正在运行独立版小助手，先从托盘正常退出，让它释放原数据目录。
3. 在 DSH 正式插件管理器中添加本地 TGZ，或使用正式 CLI：

```powershell
dsh plugin --profile desktop add 'file:C:/Downloads/xiaozhushou-harness-host-1.1.3.tgz' --ignore-scripts
```

将示例中的路径换成实际下载路径。该插件沿用原 `xiaozhushou-harness-host` 包名，更新已有插件即可。按宿主提示完整退出并重新打开 DSH，从“小助手 · 微信”入口进入工作台。

已有账号与数据按原产品目录发现；数据锁不会被强制夺取。新电脑通过“新电脑 · 连接微信”向导准备专用微信 4.1.10.27、扫码登录、识别账号并验证连接，然后自行选择允许会话及自动回复。首次插件安装需要联网安装 JavaScript 依赖。

整合包包含配套专用微信、连接组件、Python 读取环境及合同程序，不含原电脑的登录、令牌、邮箱凭据或聊天数据。DSH 核心需另行安装登录。
