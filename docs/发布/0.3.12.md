# 小助手 0.3.12 完整发布版

发布日期：2026-10-26（北京时间）。这是当前开发预览版的完整 Windows x64 发布包。

## 打开方式

在这台电脑打开 `G:\小助手`，双击 `启动最新版.cmd`。

从发布页下载完整 ZIP 时，先全部解压，再双击包内 `启动小助手.cmd`。普通使用无需进入源码目录或从多个旧版本中选择 EXE。

## 包含内容

桌面程序及其运行组件、内置合同桌面工具和 MCP 程序、产品 DSH 连接插件、完整 Git 源码快照、版本说明与文件校验清单。

沿用本机 DSH 账户及已配置的微信环境。没有打包个人配置、账户凭据、聊天记录、邮件或本机诊断日志；DSH 主程序及匹配微信环境仍是外部依赖，换电脑需要另行配置。

## 本版变化

- 合并 0.3.11 的能力批量选择、保存与缓存显示、电脑与文件权限开关，以及“等待连接／等待重载”的准确状态。
- 合并微信 DOCX/XLSX 普通文件、历史消息及转发记录附件读取。
- 修复桌面与旧微信助手同时处理同一消息的问题；桌面接管时停止旧回复进程，配置重新准备和旧入口再启动均遵守归属。
- 简化启动入口与根说明，历史说明单独归档。
- 公开发布包不写入构建机器的 DSH、微信安装位置。

## 验证边界

本次 98 个 JavaScript 文件语法检查通过，424 项全套测试全部通过。最终 Windows 程序的合成桌面验收通过，覆盖启动、任务、微信页面、能力选择、邮箱与合同入口；控制台错误列表为空，没有向真实联系人发送测试消息。102 个包内源码文件与工作区逐一匹配，两个合同程序的摘要匹配，包内未包含构建机器的 DSH／微信位置配置。

原生微信测试需要正常 Windows 权限，初次受限运行的结果未作为验收通过证据。另修正了旧验收脚本仍在“原有能力”页查找已迁到“能力选择”页控件的问题，并将缺少真实插件的检查改为使用确实依赖外部合同工具的方法，补充验证文献方法可以使用产品自带文档写入器。

压缩包会嵌入源码提交、程序核对结果和逐文件 SHA256 清单；打包完成后重新读取 ZIP 中每个文件并校验。上传结果另记录于生成目录中的 `github-publish.json`。此前功能证据见 0.3.11 和微信重复回复开发记录。

DSH 新连接组件尚需在已有 DSH 完整重开后核验；真实电脑操作及微信附件投递尚未在本版重新实发验收。电脑工具目前是截图、命令与文件操作，不包含通用鼠标键盘控制。合同内置模板为合成开发模板，正式使用应导入并核对自己的模板。
