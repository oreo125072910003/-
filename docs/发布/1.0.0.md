# 小助手 DSH 1.0.0

发布日期：2026-10-27。

## 日常微信聊天

打开已登录的 DSH，再打开小助手；现有微信保持登录。小助手会复用已导入的原微信环境并按需启动消息读取服务，继续使用原账号、允许回复的聊天和持续会话。

本版修复“打开了小助手，但读取服务没有启动”的启动缺口，以及第一次连接失败后一直不再连接的问题。暂时掉线会等待恢复；手动断开保持断开。执行前重新检查 DSH，先开小助手再开 DSH 时不会被之前的离线缓存拦住。账号、版本、凭据和人工接管核验继续生效。

## 回复速度与交付

默认最多两个不同任务同时执行，避免一项长任务占满执行队列；同一微信聊天仍串行处理。最近一次回复的总用时和排队时间在微信页显示。长任务的进度、分段文字、多附件交付、服务器回执和未知状态记录保留。

Windows 启动入口清理继承的 Electron Node 模式与 Node 注入配置，正确传递中文和含空格的数据路径。源码入口、便携入口与退出请求共用一套启动处理。

## 状态与升级

DSH 宿主组件同步升级到 1.0.0。余额不足、登录失效、接口地址不匹配和限流使用固定中文提示，保留错误分类；原始提供商错误与账户资料不向微信转发。修复微信状态区将错误对象显示为 `[object Object]` 的问题。

整合尚未正式发布的 0.3.13–0.3.16 改动，包括浏览器连接、原会话文件读取、进度提醒、多文件交付及版本化 DSH 组件加载。源代码与完整程序包在同一个版本发布。

升级前完整退出旧小助手，保留原数据。发布包不包含个人配置、密钥、聊天、邮件、日志或本机运行位置。程序未进行代码签名。

## 验证范围

离线回归、Windows 原生命令环境的启动参数、打包桌面、DSH 真实调用和微信连接分别验收。实际结果及边界见 [1.0 验证记录](1.0.0-验证.md)；模拟收发不作为真实微信投递证据。

DSH 账户额度、外部服务与网络、微信登录及已配置客户端仍是运行前提。换电脑需要配置新电脑环境；本版不会自动登录微信、绕过账号核验、重放旧消息或重试未知投递。
