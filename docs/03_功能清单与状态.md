## 六、已知限制 / 待验证

1. **发文件到群**：代码就绪，需微信窗口渲染正常时实测（当前挂载版登录的是主人号，待切回物美价廉）。
2. **微信白屏**：属客户端 Qt 渲染问题，只能重启客户端恢复；hook 消息不受影响。
3. **标题指纹**：群名超过 12 字符不校准；窗口尺寸变化（1000↔1444 宽）接近阈值时可能需重拍。
4. **小程序/视频号卡片**：只解析标题与链接，无法读内部内容。
5. **合并转发里的文件**：能给出本地缓存路径（若缓存存在），不保证所有文件都能落地。
6. **DSH 工具目录**：新增 MCP 工具必须重启 DSH 桌面应用才可见（不是「重启并应用」）。
7. **官方微信升级**：切勿让 Windows 更新把挂载版替换成官方新版，否则 hook 全断。
