自动回声不能只依赖同文/时间窗口：现只在已确认自动 outbox 与精确原生 localId 相符时忽略。不能证明为自动回声的本人外发会保守取消待处理回复。文字与表情回执另保留实际 serverId；旧已确认历史不会自动改写。

收到非成功 native JSON 不等于确认没有提交，仍保持 unconfirmed。表情 native 400 也可能来自提交过程的异常，不作为明确未提交证据。文字原生 HTTP 429 是源码可证明的提交前 busy；旧 deliveryId 的记录也不会自动重放。

## 订阅和旧组件兼容

产品名单租约为 90 秒，默认健康检查每 5 秒续租。正常断开尽力用 CAS 提交本订阅的空名单；异常退出或续租/释放失败后旧租约至多保留到期。产品端撤权和断开立即阻止该产品收发。旧项目配置与其他产品订阅独立保留，不会因撤销本产品名单删除。

reader 接口尚未支持时，UI 显示“名单待配置，新增会话尚未接收”。旧 reader 未声明真实 `selfEvents:account-conversation-v1` 时自动回复暂停，明确提示更新组件；手动路径保留。保存 UI 设置不冒充接收名单已经生效。

本次仅修改仓库源码，未更新外部运行目录、未重启 reader/Hook/DSH/微信、未打包或安装 EXE。因此代码修复不等于用户当前运行进程已经获得修复。后续部署必须核对实际 reader 与主程序版本，并单独进行受控微信验收。
