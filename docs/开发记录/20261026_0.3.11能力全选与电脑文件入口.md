# 0.3.11 能力全选与电脑文件入口

日期：2026-10-26（Asia/Shanghai）。用户希望减少能力和插件反复勾选，并明确优先恢复“操作电脑和读发文件”。本次继续沿用小助手独立产品数据和 DSH 核心，没有创建替代推理循环、启动另一个 WeChatAgent 或向真实联系人发送测试消息。

## 使用变化

- 能力中心提供“一键启用可用能力”和独立的“能力选择”标签。DSH、微信当前会话和单个 MCP 插件工具清单均可全选、清空、全选可用并保存；搜索结果批量选择仅影响当前结果，“全选可用并保存”覆盖完整目录。
- 不可调用技能、未适配工具会跳过，并显示原因。DSH 授权上限与目录限制一致，分别为 300 项技能、500 项工具，修复超过原 64 项限制不能保存的问题。
- 桌面“电脑与文件”开关独立保存。截图、文件查找、读取、命令及成果保存使用产品已有工具；权限只用于桌面发起任务，微信继续按原账号和私聊单独授权，邮件和群聊不继承。
- 界面根据实时 DSH 能力区分“已启用”“等待连接”“等待重载”。旧组件没有桌面电脑任务能力时，在提交模型任务前明确拒绝，提示从系统托盘完整退出 DSH 并重开，不再显示虚假就绪。
- 插件可批量启用并检测，工具选择与简化目录元数据持久保存；重新打开无需重新检测才能看见工具。缓存只用于展示，执行仍核对实时工具定义。技能可批量启用，工作台最多选 32 个工作方法，并记住选择。
- 修正内置技能使用 `documents.write` 而服务只声明 `document.write` 的依赖不一致。启动管理脚本读取不到进程路径时，给出可操作提示，避免空值异常或停止未经核实的程序。
