# 2026-10-25 小助手 0.3.2 界面改版与验收

0.3.2 为 UI 改版，继续沿用 0.3.1 的服务、DSH、微信协议和数据库。微信图片/文件真实投递、完整重启稳定性及 WeChatAgent 全量迁移仍按原记录列为待验或未完成，不因界面改版上调状态。

## 使用变化

- 单层顶栏与分组导航，移除重复工具栏和仿 XP 立体边框；统一中文字体、可读字号、间距、颜色、输入区、列表、状态和按钮。
- 首页突出任务描述、添加资料与提交；工作类型、流程和技能放在可展开的工作选项中，默认继续由小助手 DSH 执行。
- 微信连接正常时，账号和自动回复状态收为摘要，给会话与手动回复区留出空间；连接设置可展开，断线时默认展开。思考、发送、暂停、出错和结果待核对状态仍可见。
- 保留原有通讯录、手动回复、自动回复开关、附件、表情、能力管理、邮箱和人格设置功能；新增跳转主内容入口，键盘焦点和减少动态效果支持。
- 没有新增运行依赖或前端框架。新增 `workspace-theme.css`，继续复用原有 renderer 事件、数据和后端 API。

## 本机更新

旧 0.3.1 通过程序自带 `--quit` 正常退出，确认数据库锁释放后备份现有产品数据；不重启 Harness、微信、Hook、reader 或 MCP 看门狗。

完整业务数据、受保护凭据与 Chromium Local State 已备份；略过可再生成的 Chromium 缓存。数据库、受保护凭据和 Local State 的备份摘要均与原文件一致。证据在 `dist/verification/ui-upgrade-0.3.2.json`，备份保留在原数据目录旁，不进入 Git。

桌面“小助手预览版”指向新 0.3.2 程序，显式沿用原物理数据目录。新版进程已取得原数据库锁；升级前后完整性检查均为 `ok`，6 项任务、17 条微信消息、1 条 DSH 会话映射、36 条事件及其他表记录均保留，未创建测试消息。原 0.3.1 发布文件夹保留。

数据库与截图/构建证据为本机文件，均不提交到源码仓库。基础版审核材料仍固定 0.3.1 / `0593f2a`；本轮改版单独说明。
