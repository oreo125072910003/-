# DSH 共享包依赖修复（2026-10-26）

小助手桌面版本保持 **0.3.12**。本次更新的独立组件为 `xiaozhushou-harness-host@0.3.8` 和 `dsh-social-bridge-plugin@0.3.10`，未重新发布桌面安装包。

## 问题与修改

- 当前 DSH 及其公共包版本为 `0.2.1-rc.3`。通过同一安装自带的运行时解析器验证，修复前两个插件实际加载了 `dsh-llm@0.2.0-rc.2`，公共函数和类与宿主实例不同。这证明存在重复版本加载，不能据此认定它导致了此前的 HTTP 404。
- 两插件移除 `dsh-llm` 直接依赖，将 `dsh`、`dsh-llm` 声明为可选 peer，最低支持 `0.2.1-rc.3`。社交插件锁文件移除旧公共包及其独占依赖。
- 宿主原补丁使用候选源目录的绝对 URL，处于 profile 运行时解析范围之外。现在生成相对于已安装包的 `entry-<revision>.mjs`，内部相对模块继续带 revision。入口使用独立文件名，因为当前 DSH 会将相对补丁路径中的问号当作文件名字符。
- 准备结果改为 `dependencySource: harness-runtime`，删除以私有 `node_modules` 是否存在判定依赖就绪的逻辑。
- 真实回复测试还确认旧名称 `deepseek` 返回 `NO_ADAPTER`。宿主默认值和社交组合补丁改用当前 DSH 已注册、复用现有登录的 `deepseek-account`。
