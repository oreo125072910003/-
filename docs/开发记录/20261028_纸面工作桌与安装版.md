# 纸面工作桌与 Windows 安装版

本轮交付目标为独立桌面 1.0.6、完整 DSH 插件 1.1.4。用户授权继续完成旧包上传、使用指定设计技能优化前端、审查重复代码、制作可安装版本，并在验收后自动发布到现有 GitHub 仓库。

## 设计依据

通过 `skill-installer` 从 `houxin0010/distinctive-ai-design` 仓库根目录安装 `distinctive-ai-design`，读取完整 SKILL.md 和媒体与评审参考后应用。技能安装在本机个人技能目录，不复制进入产品运行依赖。

在纸面工作桌、紧凑工具台、通信收件箱三个方向中，选择纸面工作桌：面向个人日常工作、微信与邮箱接续，以暖白底、石墨文字和少量墨绿强调建立层级。沿用现有 Electron、原生 preload 与 DSH 嵌入工作台，不新增远程字体、图片或界面运行依赖。

主任务分配、通信、任务记录和能力管理仍走原接口与权限。设计评审使用真实 Electron/preload 的合成数据截图，未读取个人会话或向外发送消息。第一轮独立评审指出微信首屏头部偏高、最近工作位置偏后、能力页状态重复；第二轮集中修正这些问题。审美评审与功能验收分开记录。

## 有边界的代码精简

- 两套叠加样式合并为单个 styles.css，删除 workspace-theme.css 和对应静态路由，清理被覆盖的声明及确定不再产生的旧选择器。
- 桌面主进程与 DSH host 的 56 项公开服务名单由 contracts/ui-service-methods.mjs 统一维护。沙盒 preload 保留固定窄接口，由测试检查一致性；不放开沙盒模块加载，也不公开内部审批或数据库方法。
- 原 DSH 插件的数据目录发现提到 contracts/product-data.cjs，桌面启动与插件使用同一实现。已存在的 Codex 重定向数据可被新安装入口发现；多个数据库时拒绝猜选，显式路径与环境变量仍优先。
- 图片尺寸、像素预算和局部坐标规则集中到 image-input.mjs，两层信任边界仍独立调用。补修稀疏坐标数组可穿过旧数组检查的问题，不删除文件摘要、消息绑定和授权检查。
- 插件实际版本由自身 package.json 读取；插件 smoke、官方安装验收与便携环境检查从当前版本定位候选包，消除过期的硬编码版本。
- 发布脚本支持恢复匹配提交的草稿，只保留并复用大小和 SHA256 一致的已上传附件；Windows 上传使用隔离临时文件，凭据不出现在命令行或保存的配置中。

历史源码副本、协议兼容和两层授权校验有明确用途，本轮不为减少行数删除这些内容。

## 安装器

使用官方固定版本 NSIS 3.13 的便携编译器，下载并校验归档及解出的文件，不全局安装开发工具，不新增产品运行依赖。构建入口为 `npm run package:installer`，输入必须是没有本机配置的 distribution 应用包。

安装到当前 Windows 用户的程序目录，无需管理员权限；桌面和开始菜单直接启动产品 EXE。安装前拒绝无关非空目录、链接、卷根目录和被占用的程序；不强制结束任务。卸载只删除生成清单内的程序文件，不递归删除安装目录，保留个人数据、微信、DSH 和程序目录中不属于安装器的文件。

真实安装验收通过 `/ISOLATED` 使用临时目标，跳过真实快捷方式和卸载登记，其余程序安装、占用检查、应用启动及卸载路径保持一致。不以该验收冒充在第二台电脑完成账号登录。
