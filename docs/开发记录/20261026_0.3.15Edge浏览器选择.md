# 0.3.15 Edge 扩展连接修复

用户确认安装后，本机检测到 Edge Default 配置中存在 Playwright Extension 0.4.0。使用实际打包的 0.3.14 浏览器服务调用 `tabs/list`，返回的是 Chrome 默认资料目录下找不到扩展；因此此前工具目录握手成功不能证明连接到了用户浏览器。

官方依赖当前的程序接口在扩展模式中忽略 `browser.launchOptions.channel`，使用空 CLI 选项解析浏览器，默认 Chrome。现改用官方 MCP CLI 和 SDK 的标准输入输出传输，通过独立子进程明确传入 `--extension --browser`。Windows 检查 Edge、Chrome 的扩展安装目录；优先使用已装扩展的 Edge，并保留 `PLAYWRIGHT_MCP_BROWSER` 的明确配置。只检查安装目录，不读取浏览器登录数据。浏览器选择只传给各连接子进程，不修改系统环境变量。

首次连接为主人预留五分钟完成选页，成功连接后各操作恢复 75 秒超时。保留原有 DSH 核心、按身份隔离、授权检查、串行操作、取消不重放和成果归属。Electron 子进程显式使用 Node 模式，移除继承的 `NODE_OPTIONS`；连接关闭时释放 MCP 子进程。应用升级为 0.3.15，宿主插件版本不变。

完整源码测试 454 项通过，源码检查 104 个文件、0 失败。浏览器实连结果和本机部署结果以本机诊断目录中的后续报告为准；尚不能据此称 ChatGPT 已经生成图片。诊断目录 `G:/dsh-diagnostics/20261026` 不进入 Git。

## 本机实际验证

桌面已平滑退出 0.3.14 并以原数据目录启动 0.3.15，打包 GUI 合成验收通过、控制台无错误。实际扩展连接后读取到 `ChatGPT` 页面和“询问 ChatGPT”输入框，未发送网页聊天、生成图片或向微信外发。页面另有工作空间成员达到使用上限的提示。

真实 DSH 模型检查两次均在调用浏览器工具前失败。核对本次独立工作区的原生会话 `turn/end`，实际错误为 `ACCOUNT_QUOTA`、HTTP 402、`Insufficient Balance`，不是浏览器扩展连接失败。余额问题需要账户侧处理后再继续 DSH 生图链路验收；本轮未充值、开启自动充值或更改模型服务。最终证据保存在本机 `browser-connection-final.json`。
