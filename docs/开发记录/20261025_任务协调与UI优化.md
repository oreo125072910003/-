## 设计方案

产品为长期使用的中文个人桌面助手，DSH 始终是核心。设计围绕“交代一件事、随时看进度、直接处理消息”，不做营销落地页。

- 色彩：画布 `#F5F8F8`、内容 `#FFFFFF`、正文 `#203938`、辅助文字 `#607674`、主色 `#147D73`、分隔线 `#DFE9E6`。
- 字体：Windows 中文界面采用 `Microsoft YaHei UI`，英文采用 `Segoe UI Variable Text`；正文 13px、输入 15px、标题 28px。
- 布局：单层顶栏、220px 导航、主工作区；首页主输入与右侧真实状态分工清楚，常用入口保持可见。
- 原则：取消仿 XP 高饱和渐变、立体边框和重复工具栏；用留白和字号组织内容，圆角区分输入区、列表和状态标签。有限动画，并尊重系统减少动态效果偏好。
- 方案复核：这不是通用数据仪表盘，不添加装饰性统计图或虚构活动；任务、成果、连接与微信状态全部沿用现有服务数据。
