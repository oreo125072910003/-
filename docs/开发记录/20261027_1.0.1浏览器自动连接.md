# 小助手 1.0.1：浏览器自动连接

2026 年 10 月 27 日。用户要求独立“小助手”也能方便地连接日常浏览器，沿用已验证的 Playwright 扩展方式。

## 实现

- 在现有浏览器服务中加入本机配对配置，固定浏览器与配置目录；本机已配对 Edge 的 Default 配置。
- 扩展连接令牌使用产品原有的 Windows 加密存储，普通配对文件只保存浏览器和配置目录。令牌不会进入源码、安装包、模型参数或对话记录。
- 配对程序使用与主程序相同的 `desktop` 数据目录，确保 Windows OSCrypt 加密信息能由主程序解密。本机配对过程中发现并修正了辅助程序使用默认 Electron 数据目录的问题，原有凭据保持保留。
- 向 Playwright 传入既有令牌与配置目录，实现已配对浏览器自动连接。未配对环境继续使用原有的人工选页方式。
- 过滤上游标签页列表中可能出现的扩展令牌；上游报告断开时释放失效连接，下一次观察重新连接，不自动重放结果不明的点击或输入。
- 更新本轮 DSH 执行说明，让她以真实连接状态为准，已经配对时不反复要求主人选页。

核心仍由现有 DSH Harness 执行，复用原登录；产品的各会话授权与标签页组隔离沿用现有实现。

## 使用

小助手已经保存本机浏览器配对。后续直接在原来已授权使用电脑的对话中提出网页任务即可。网页自身的登录或验证码仍以实际页面要求为准；更换浏览器配置或重置扩展令牌后需要重新配对。
