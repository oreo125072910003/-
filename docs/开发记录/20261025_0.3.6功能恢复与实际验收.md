# 0.3.6 功能恢复与实际验收

日期：2026-10-25。本机已运行 0.3.6，继续使用原产品数据和已经登录的 DSH，不创建第二套 WeChatAgent 或替代推理循环。用户要求全部功能推进，并授权自行决定实现顺序。

## 已完成的产品变更

- 原 DSH 会话恢复后，重新挂载属于该原生 Agent 的本轮工具保护。旧会话曾缺少保护标记，导致 `SAFE_PRESET_UNAVAILABLE`、无法回复；前置修复提交为 `06e4472`，本版实际加载该修复。
- 增加 13 个有限产品工具。DSH 原生 Agent 按本轮授权注册；实现经短期本机能力连接进入产品服务，每轮结束撤销连接，不复制模型账户。
- 文档生成真实 DOCX/PDF；文字保存、资料读取、独立 SVG 渲染 PNG、当前任务成果选择和原聊天表情选择接入原工作流程。绘图适用于矢量插画、卡通、图表，不等于写实图片模型。
- 截图、目录、文件读写、本地命令和导出通过独立私聊电脑授权运行。本地写入不覆盖原文件，导出建立校验快照；任务停止、权限撤销、输出和执行时限贯穿调用。
- 邮件工具可查看现有账号、缓存收件和正文，或建立草稿，没有模型直接发送操作。桌面已有账号表单、标准 IMAP/SMTP 和明确发送流程继续保留。
- 自动回复在原有出站队列中先交付选定媒体，再发送正文；目标来自原始收到的消息。媒体失败或结果不明时保留成果，发出准确状态说明，并停止后续媒体发送，避免“声称已发”的回复。
- 媒体传输补齐任务取消与最终提交检查。任务失败通知沿用当前连接、聊天允许范围和发送保护。
- 能力中心增加“修复常用功能”；启动修复等候微信连接就绪，避免刚启动就把有效连接判为离线。保留旧的技能、工具选择和原聊天范围。
- 工作台和任务详情显示真实微信问题，历史记录只派生显示标题，不改写原提示词或历史消息。
- 安装包解包本地原生模块和 PowerShell 资源；修复安装包自检结果目录误写入 ASAR 的问题。
- 新增统一桌面启停/状态脚本和可备份的入口安装脚本。本机统一目录 4 个入口已切换，旧入口已备份；不再经这些入口启动旧 WeChatAgent。

## 明确仍未完成的部分

1. **微信图片/文件真实投递尚未通过。** 当前微信原生可访问性只暴露窗口和容器，缺少可核对的目标标题、输入框、预览与发送控件。现有 Hook 的图片路由也不可用，源码原生图片 ABI 未验收。保留文件成果并准确说明失败；不使用盲点、清空草稿、盲按回车或不确定后自动重发来冒充恢复。
2. **邮箱没有已有有效授权。** 本机账号数为 0，没有真实收发验收；现有账号配置入口和草稿流程可用，不伪造登录状态。
3. **合同验证范围是能力连接和 API 状态。** 正式业务模板、真实字段、合同生成与外发不能由状态查询代替验收；文档合成验收也不等于真实合同验收。
4. 普通微信文件收到后的下载闭环、扫描件 OCR、写实图片模型、真实视觉输入、Office 复杂版式和长时间稳定性仍未完成完整验收。本版没有把所有迁移项标成完成。

## 维护入口

- `scripts/launch-desktop.ps1`：按主工程版本启动并沿用明确的数据目录。
- `scripts/manage-desktop.ps1 -Action start|stop|restart|status`：正常启停；退出未确认时保留原进程与数据，不强杀。
- `scripts/install-desktop-entrypoints.ps1 -EntryDirectory <绝对目录>`：备份旧入口后安装上述管理入口。
- 能力中心“修复常用功能”：在现有账号、聊天和原选择基础上恢复，返回逐项结果；不把修复配置当成全部功能已经真机验收。
