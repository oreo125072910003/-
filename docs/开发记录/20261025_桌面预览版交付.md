# 小助手 0.1 桌面开发预览版

交付日期：2026 年 10 月 25 日。该版本是完整开发计划的首批可运行成果，继续使用 Harness 核心，未替换旧微信运行环境。

## 启动

双击项目根目录的 `启动小助手预览版.cmd`，或运行 `dist/releases/0.1.0/小助手-win32-x64/小助手.exe`。必须保留整个发布文件夹，不能只移动 EXE。

首次打开是空工作台，不自动生成示例任务。可以添加资料并选择“整理资料”，完成后打开真实的 Markdown 清单与 JSON 校验文件。“能力中心”可打开本地合同表单；其内置模板为合成开发模板，正式业务应导入并核对自己的模板。

AI 文本分析与写作需要在“助手设置”填入有效模型 API Key。支持的本机组合是 Harness 0.2.1-rc.2 与 sdk 配置；模型地址采用 Messages 兼容接口，默认 `https://api.deepseek.com/anthropic`。密钥由 Windows 系统保护保存，不写入普通设置或数据库。本次没有复制原 Harness 个人账户或发起付费模型调用。

默认数据位于 `%APPDATA%/XiaoZhuShou`。产品数据库、任务资料副本、成果、受保护凭据、独立 Harness home 和合同资料分别保存。关闭窗口后驻留托盘，右键托盘可退出；退出会停止本应用拥有的执行任务，已有资料和成果保留。

## 现在可用的内容

- 独立 Electron 桌面、中文工作台、任务列表、详情与成果入口。
- 持久 SQLite 记录，单写入者锁、重启中断识别、失败与取消状态。
- 用户选择文件后的受控复制，不修改原件；本地资料目录、文本预览和 SHA-256 校验。
- Harness 正式 CLI 发现、独立 home、SDK 协议、人格注入与结果保存。
- 模型任务受限为文本分析和写作；不开放任意 shell、文件工具、第三方 MCP 或子 agent。
- 系统保护的模型密钥、可编辑名字与人格、真实能力状态与明确错误。
- 恢复完整源码并编译的合同表单和合同 MCP；从能力中心打开本地表单，使用独立数据目录。
- 电脑桥接的明确业务失败、版本协商、有界读取及白屏误报等先行修复。

## 尚未完成

没有完成真实模型账户连通与付费任务验证；仅检测到 Harness 不能宣称模型已就绪。现版本的 AI 输入只支持文本附件，Word/PDF/图片解析仍待受控工具接入。

微信原链路保留，但没有接到新桌面入口；邮件、可管理的 MCP/Skill、外部 worker、长期项目记忆、主动调度和完整出站队列继续按计划开发。合同 GUI 的实际操作、Word 视觉版面及正式模板尚未验收。电脑桥接网页出口与 HTTP 生命周期问题仍未解决，未因此开放到新桌面。

当前新产品使用原生 ESM 加运行契约验证，优先实现可测试闭环以复用现有 JavaScript；后续按模块成熟度引入静态类型检查。这是实现顺序调整，不重写 Harness 的推理循环。SQLite 使用 sql.js 的单实例事务快照与原子替换，写入成功后才确认保存；尚不是多进程共享数据库服务。

发布包是未签名开发预览版，面向本机试用。尚未完成自动更新、正式安装器、跨用户完整验证和72小时连续运行测试。

npm run package
python tests/pcbridge_regression.py
python 代码/合同助手/desktop/test_native_args.py --exe 代码/合同助手/desktop/out/desktop-release/合同填写小助手.exe

打包采用显式文件清单，只包含新桌面层、必要的 sql.js、无密钥程序位置和合成合同成品；不打包旧个人配置、聊天记录、微信数据和既有真实合同样例。缓存 Electron ZIP 经 npm 包自带摘要核对后复用，避免重复联网下载。
