# 0.3.13 已登录浏览器连接

用户报告小助手不能通过已经登录的 GPT 网页聊天和生图。实际核对：桌面与已授权微信私聊具有电脑权限，但没有浏览器操作 schema；旧 pcbridge 的 `gpt_draw` 仅调用固定免费图片接口，`ask_gpt` 与通用 CLI worker 分支关闭，不是网页版 ChatGPT 通道。

新增 `xiaozhushou_browser` 产品工具，依然由 DSH 核心决定工具调用；产品服务使用微软官方 `@playwright/mcp@0.0.83` 和 MCP SDK 的内存传输接入现有浏览器扩展。支持查询参数、标签页、页面快照、导航、点击、输入、按键、等待、表单、选项、悬停和截图。没有复制 cookie、提取账号 token 或调用未公开网页接口；不要求另外填写 API Key。

浏览器属于电脑能力。桌面需保留电脑开关；微信限定已核验且单独开启电脑权限的私聊，各身份分开客户端和标签组，普通聊天、群聊和文字 worker 不获得该工具。功能恢复只为已开启电脑能力的私聊补齐浏览器工具。取消或失败不自动重放点击与输入。图片下载复制为本轮独立成果，可沿原有 attachment 流程交付原会话。

首次安装扩展、浏览器连接确认、选择允许的标签页以及登录验证仍由主人完成。新增执行说明要求模型先查真实浏览器工具与页面，不得继续用旧聊天中的“没有浏览器工具”代替实际检查；生成成功、文件落地、微信送达分别确认。

源码验证：浏览器隔离、授权撤销、取消、下载归属、宿主工具策略与微信授权定向测试通过。官方 MCP 使用真实依赖完成工具目录握手，返回 11 项受支持浏览器动作。浏览器页面是否实际连接、ChatGPT 是否实际出图须以随后运行证据为准，不能用目录握手代替。
