首次正式安装成功后，产品宿主端口没有出现。检查确认生成补丁使用候选目录内 `index.mjs` 的绝对文件 URL；该源目录没有 `node_modules`，Node 报 `ERR_MODULE_NOT_FOUND: @deepseek-ai/dsh-llm`。profile 中的依赖不能替该绝对源路径完成解析。
